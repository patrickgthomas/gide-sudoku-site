# Gide Sudoku website

The live landing page is https://gidehub.com/games/sudoku/.

The canonical source is `src/pages/games/sudoku/index.html` in `patrickgthomas/trustedstranger-site`. Run `node build.mjs` there, then copy the generated page here with root-relative asset/navigation paths resolved against https://gidehub.com. This mirror can be hosted independently without changing the canonical link.

As of November 9, 2026, `sudoku.gidehub.com` was not serving a working page. The hub URL is used in navigation until separate hosting/DNS is verified. No App Store download button is shown before public release.
